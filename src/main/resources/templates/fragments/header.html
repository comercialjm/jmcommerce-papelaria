Como testar esta loja

Esta loja é um projeto de demonstração da JM Code Studio — nenhuma cobrança de verdade é feita. Fique à vontade para navegar e simular uma compra completa:

  1. Escolha um produto no catálogo e clique em "Adicionar ao Carrinho".
  2. Vá até o carrinho e digite um CEP válido para calcular o frete.
  3. Clique em "Finalizar Compra" e preencha seus dados (podem ser fictícios).
  4. Na tela de pagamento do Stripe, use o cartão de teste:
    4242 4242 4242 4242
    Qualquer data de validade futura, qualquer CVC, qualquer CEP.
  5. Pronto! Você verá a confirmação do pedido — e, se usar um e-mail real, recebe a confirmação por lá também.

Gostou do que viu? Fale com a JM Code Studio sobre um sistema assim para o seu negócio.
